#### 总结共性,然后复制
- 材料选择,选择自己感兴趣的材料。例如书、youtube、美剧、电影等等。视频里学习比较的好,没有人提到过教科书
- 巨大的输入量。小说、美剧、阅读、影视剧。 每天3-4h(对于我来说,没有这个时间)
- Input over output。强调输入,替代输出
- 语言习得源于输入
- 输入的资料一定要地道的资料。因为垃圾进，垃圾出。
- 可理解性。要依附于语境、场景来学习和理解
- 有趣。有趣才会学习
- 最后才是输出。输出是自然而然的
- 重点: 坚持、持续
