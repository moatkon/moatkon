#### grep

```sh title="在当前目录下查找文件内容是否包含指定字符"
grep -r "要搜索的字符串" .

# 解释
-r: 递归搜索,包括所有子目录
"要搜索的字符串": 你想要查找的具体内容,用引号括起来
.: 表示从当前目录开始搜索
## 其他参数
-i: 忽略大小写
-l: 只显示文件名,不显示匹配的内容
-n: 显示匹配内容所在的行号
```
